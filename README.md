## 🌟 Overview

**Glamo** is an elegant front-end web application designed for cosmetics, skincare, and beauty storefronts. The project emphasizes visual polish, modern SCSS design patterns, structured media management, and smooth responsive design across all screen sizes.

---

## ✨ Key Features

- **Elegantly Crafted UI:** Minimalist interface tailored specifically for cosmetics and beauty product presentations.
- **Modular SASS/SCSS Architecture:** Scalable partials (`_header.scss`, `_navbar.scss`, `_advantages.scss`, `_faq.scss`, `_contact.scss`, `_use-metod.scss`, `_footer.scss`) compiled to CSS.
- **Fully Responsive Layout:** Optimized using CSS Grid and Flexbox for seamless displays on mobile devices, tablets, and desktop screens.
- **Dynamic JavaScript Logic:** Smooth client-side interactions and interactive UI logic handled via `main.js`.
- **Organized Asset Structure:** Separated vector icons (`/icons`) and graphic assets (`/images`) for performance optimization.

---

## 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** CSS3, SCSS (Sass)
- **Scripting:** JavaScript (ES6+)
- **Icons & Media:** SVG vectors, PNG, JPEG
- **Deployment:** GitHub Pages
